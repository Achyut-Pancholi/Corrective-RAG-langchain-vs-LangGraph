================================================================================
          ADAPTIVE RAG (CRAG) — TESTING GUIDE & BENCHMARK SCENARIOS
================================================================================

This guide provides test scenarios to demonstrate the architectural differences 
between Standard Linear RAG (LangChain) and Self-Correcting Graph RAG (LangGraph CRAG).

Dataset Ingested: 1,245 chunks across 12 Research Papers (PDF) + Custom Domain Docs (TXT).

================================================================================
1. PREREQUISITES & RUNNING THE APP
================================================================================
1. Activate virtual environment:
   .\venv\Scripts\Activate.ps1

2. Launch Streamlit UI:
   streamlit run app.py

Open http://localhost:8501 in your browser.

================================================================================
2. TEST SCENARIO 1: The Winning CRAG Showcase (LangChain Fails -> LangGraph Recovers)
================================================================================

Target Query:
"How do researchers map different Earth terrain types and what spatial resolution bands were utilized from the European satellite?"

A) Select "LangChain — Baseline RAG"
-------------------------------------
- RESULT: Refusal / Failure
  "I'm sorry, but the provided documents do not contain information about the spatial 
   resolution bands used from a European satellite, nor do they describe the specific 
   methods researchers use to map different Earth terrain types."
- EXECUTION TRACE:
  - Question received
  - Documents retrieved (Retrieved 2 documents)
  - Answer generated
- WHY IT FAILS: Baseline RAG performs a single-shot retrieval pass. Vector search returns 
  tangential background chunks from ATLAS altimeter systems that do not contain the actual 
  satellite mapping bands. Baseline RAG blindly feeds these into the LLM, resulting in a refusal.

B) Select "LangGraph — Corrective RAG"
--------------------------------------
- RESULT: Accurate, Complete Answer
  "Researchers map different Earth terrain types using spectral data collected by the MERIS 
   and MODIS sensors aboard the European satellite ENVISAT.
   - MERIS provides daily images in a set of spectral bands.
   - MODIS supplies 36 spectral bands covering all land surfaces with spatial resolutions 
     ranging from 250 m to 1 km..."
- EXECUTION TRACE:
  - ✅ Question received
  - ✅ Documents retrieved (Retrieved 2 documents)
  - ⚠️ Documents graded (Documents insufficient)
  - ⚠️ Query rewritten (New query: terrain classification mapping European satellite spatial resolution bands)
  - ✅ Documents retrieved again (Retrieved 2 documents)
  - ⚠️ Documents graded (Documents insufficient)
  - ⚠️ Query rewritten (New query: European satellite terrain classification spatial resolution bands)
  - ✅ Documents retrieved again (Retrieved 2 documents)
  - ✅ Documents graded (Sufficient context found!)
  - ✅ Answer generated
- WHY THIS PROVES CRAG WORKS: 
  CRAG's Document Grader inspects retrieved documents, identifies that the initial retrieval 
  lacked factual data, rejects the noise, and executes an automated query rewrite loop to 
  retrieve the exact technical section from the ENVISAT satellite study.

================================================================================
3. TEST SCENARIO 2: Direct Technical Accuracy (Demonstrating Fast Parity)
================================================================================

Target Query:
"What specific accuracy score was achieved by the novel convolutional neural network model when diagnosing lung cancer on CT scan images?"

A) Select "LangChain — Baseline RAG"
-------------------------------------
- RESULT: "The novel convolutional neural network model achieved a 100% testing accuracy when diagnosing lung cancer on CT scan images."

B) Select "LangGraph — Corrective RAG"
--------------------------------------
- RESULT: "The novel convolutional neural network model achieved a 100% testing accuracy when diagnosing lung cancer on CT scan images."
- EXECUTION TRACE:
  - ✅ Question received
  - ✅ Documents retrieved (Retrieved 2 documents)
  - ✅ Documents graded (Sufficient context found)
  - ✅ Answer generated
- WHY IT HAPPENS: When initial vector retrieval successfully retrieves the ground-truth document 
  on the first pass, CRAG grades it as sufficient and routes directly to generation without 
  unnecessary query rewrites or latency.

================================================================================
4. TEST SCENARIO 3: Negative / Out-of-Domain Query (Hallucination Prevention)
================================================================================

Target Query:
"What was the battery efficiency of the electric vehicle powertrain tested in the 2025 automotive study?"

A) Both Flows:
--------------
- RESULT: "I don't know based on the provided documents."
- WHY IT HAPPENS: Both flows strictly adhere to prompt constraints and avoid hallucinating facts 
  when information is absent from the knowledge base.

================================================================================
5. DATASET & ARCHITECTURE NOTES
================================================================================
- Document Ingestion: src/ingestion/loader.py (Supports PDF and TXT with RecursiveCharacterTextSplitter)
- Vector Store: src/retrieval/vector_store.py (Cached Chroma DB on disk at data/chroma_db)
- Embeddings: HuggingFace all-MiniLM-L6-v2 (Local, zero API cost)
- LLM: Groq openai/gpt-oss-20b (Ultra-low latency inference)
